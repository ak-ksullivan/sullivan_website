Easy — GitHub's web interface handles this with drag-and-drop, no command line needed. Here's the walkthrough:

Uploading via the GitHub website

  1. Go to github.com/ak-ksullivan/sullivan_home and make sure you're signed in.
  2. Click the Add file button (near the green "Code" button), then choose Upload files.
    • Alternatively, you can just drag the files from your computer and drop them anywhere onto the repository page — GitHub opens the uploader automatically.
  3. Drag in your files: index.html, fraya.jpg, jim-quatro.jpg, and kelly-fraya-wdc.jpg. You can select all four at once.
  4. Scroll down to the Commit changes section. A commit is just a saved change — type a short note like "Add website files" (GitHub pre-fills something reasonable).
  5. Keep the option "Commit directly to the main branch" selected, and click Commit changes.

A couple of tips:

  • Don't rename files during upload — the page looks for exactly fraya.jpg, jim-quatro.jpg, etc., so the names must match what's in the HTML, including lowercase.
  • Make sure the files land in the root of the repo, not inside a folder.
  • If any file is larger than 25 MB, GitHub's web uploader won't take it — but your photos should be well under that. (If you want faster page loads, resizing photos to ~1600px wide before uploading is a nice touch, but not required.)

Then turn on Pages

  1. In the repo, go to Settings → Pages (in the left sidebar, under "Code and automation").
  2. Under Build and deployment, set Source to Deploy from a branch.
  3. Choose branch main and folder / (root), then Save.
  4. Wait a minute or two, refresh the Pages settings page, and a green box will show your live URL: https://ak-ksullivan.github.io/sullivan_home/

That's it — the whole family (human and canine) will be on the internet. Once it's live, if anything looks off — a missing image, styling glitch — tell me what you see and I'll troubleshoot it with you. And when you're ready for the custom domain, that's just two settings tweaks away.
